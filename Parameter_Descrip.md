# Parameters Description

## afl_lidarOdometry

### command line parameters

| Parameter      | Description |
| ----------- | ----------- |
| rosbag_path (string)      | rosbag file absolute path       |
| lidar_type (int)  | 1 LIVOX 2 VELODYNE 3 OUSTER 4 HESAI        |
| lidar_topic (string)  | topic for lidar msg        |
| match_stability_threshold (float)   | the threshhold used in the Section 3.1.3 of paper<sup>1</sup>       |
| motion_linearity_threshold (float)   | the threshhold used in the Section 3.1.2 of paper<sup>2</sup>.        |
| bag_start (float)   | data start time with respect to the bag start (second)        |
| bag_dur (float)  | data during(second)        |

<sup>1</sup>To select the value of matching stability threshold, we performed the adaptive frame length LiDAR odometry using one sample sequence (e.g., collected in the indoor scene with some big planes) with multiple times through increasing the matching stability judgment threshold until the mapping result gets clear and sharp. We can easily evaluate the mapping result by checking the plane fitting error. 

<sup>2</sup>The motion linearity threshold can be selected by: point error/point distance. For example, 0.1 are calculated approximately by 5(cm) ÷ 30(m) ×
180 ÷ π. 


### parameters defined as macro variables

| Parameter      | Description |
| ----------- | ----------- |
| VoxelSize      | point cloud downsampling       |
| LENGTH_DT  | step of the frame length (second)        |
| MINI_FRAME_LENGTH   | minimum frame length (second)        |
| MAX_FRAME_LENGTH   | maximum frame length (second)       |



# tight_LiCalib

### command line parameters

| Parameter      | Description |
| ----------- | ----------- |
| rosbag_path (string)      | rosbag file absolute path       |
| lo_pose_path      | lidar odometry traj path (generated by performing afl_lidarOdometry)      |
| lidar_type (int)  | 1 LIVOX 2 VELODYNE 3 OUSTER 4 HESAI        |
| lidar_topic (string)  | topic for lidar msg        |
| bag_start (float)   | data start time with respect to the bag start (second)        |
| bag_dur (float)  | data during(second)        |
| still_time (float)  | stillness duration       |

### parameters defined as macro variables

| Parameter      | Description |
| ----------- | ----------- |
| MapVoxelSize      | downsampling voxel size for map|
| ScanVoxelSize  |downsampling voxel size for scan|
| LidarWeight   | balance the LiDAR factor and IMU factor|
